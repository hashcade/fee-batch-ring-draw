# Project guidelines

- Write source, comments, scripts, and documentation in English.
- Keep README focused on this mod's current features, requirements, installation, configuration, Credits, and standard license. Do not include personal cheat lists, companion-cheat guidance, predecessor migration history, development/release workflows, or detailed implementation notes; keep engineering details in the existing docs instead. Preserve concise, accurate author/dependency attribution in Credits, following the other mods. Never remove Credits or License when simplifying README.
- Do not add personal cheat files, companion cheat directories, their tests, or their maintenance documentation to this mod repository. When the user requests changes to an external shared cheat file, edit that file only; do not copy it into the repository or release packages.
- Keep commits atomic. Do not release or install unless explicitly requested.
- Retain the existing ring transaction safety checks and Cobalt 1.31 ABI conventions.
- Scope local verification to the change; CI owns full regression checks.
- Model native menu inheritance accurately: BasicMenuItem has 27 virtual slots; MapBasicMenuItem adds flag/help/map-attribute slots 27-29. Never fabricate extra base-class slots in fixtures. Select the actual native item type and constructor, and check only the interfaces that the feature uses.
- Never modify user saves or installations. Supplied executable analysis is read-only.
- Check game version, Build ID, and every native entry/signature before hooking.
- Run transactions synchronously on the original game menu thread.
- Preserve native prices, probabilities, acquisition records, achievements, and equipped rings. Unlimited shop stock applies to the armory, item shop and flea market, including sold-out unlocked goods; retain chapter/unlock checks, prices, inventory limits and one-time ownership rules for outfits/accessories. Override stock reads/decrements, not saved inventory or unrelated variables.
- Keep the game's original level display. Do not add internal or cumulative level information to the UI.
- Preview only a copy of RNG state; never advance or restore the live RNG to skip a full result.
- Stop before an unaffordable or unrecordable result. Never retry after an attempted transaction.
- Keep the original outer flow; bypass presentation before changing the scene, background, or title bar.
- Expose requested options through Cobalt's in-game Plugin Settings. Persist them automatically in an independent SD-card file, never custom game/save variables. Keep batch creation at 300 by default and retain original one/ten choices. Do not add logs, result windows, or quantity dialogs.
- Integrate batch ring creation, batch melding, fast ring cleaning, fast fishing, fast perfect strength training, and repeatable cooking in one plugin. These features are always enabled; do not add feature toggles or increase activity allowances.
- Include the explicitly requested food-list stock bypass and inventory-free ordinary gifts. Scope gift changes to the original ordinary-gift menu and settlement; never bypass global item inventory, special relationship prerequisites, or plot checks.
- Ordinary Wyvern Ride finishes after its opening at the current difficulty's native SSS boundary. Retain the original ending, record updates, rewards and eligibility. Do not fabricate target counts, perfect scores, unlocks, or additional attempts; preserve event/test/pause/retirement paths.
- Confirmed batch melds skip presentation before header/footer/background changes. Preserve native settlement and outer resource cleanup; do not synthesize skip-button input.
- Skip presentation battles in ordinary and paid Emblem training. Automatically skip messages only within native C/B/A support or Emblem bond calls, including paid training. Preserve native calculation, EXP, growth, activity allowances, fragment cost, script execution, viewed/completion callbacks, achievements and cleanup. Never bypass the whole event or fabricate its completion flags. Story and Pact Ring conversations remain unchanged. Automatic support dispatch must keep native eligibility and normal completion, not directly force ranks or viewed flags. Leave battle saves, rewind limits and resource refills outside this mod. Do not install or release without an explicit request.
- Exploration collection uses the original menu on its game thread. Collect only generated pending sources, retain donation/adoption rules and shared capacity budgets, and never mark unrelated interactions complete. Ordinary villager gifts must pass the native result-index/access-count gate; only their native conversation counter is consumed. Collection must not consume support/story interactions or generate new drops.
- CommonRewardSequence.CalcRewardItemList grants inventory; CommonRewardDialog.CreateBind displays the returned dictionary. Never follow CalcRewardItemList with another reward-granting sequence.
- Document Nintendo Switch installation before emulators. Use standard MIT attribution.
